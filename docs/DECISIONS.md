# Decision log (site-wide)

Significant site-wide decisions, newest first, with the reason. Tool-specific decisions are in each tool's
`DECISIONS.md`. The rules themselves are in [`AGENTS.md`](../AGENTS.md); a row marked **Superseded** is kept for
history only.

| 2026-11-23 | New caveat kind `weakSource`, labelled "Weaker source": a page from a fitness app, magazine or shop rather than a professional body, used only where no better source was found (first used for four exercise-planner how-to links). Shown next to the link and in any drawing made from it | Owner, 23 Nov 2026: "You can use app or magazine sites if no better sources can be found with the appropriate disclaimer on accuracy" |
